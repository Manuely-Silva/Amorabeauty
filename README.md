# Amora Beauty 💄

Projeto de desenvolvimento web para a **Amora Beauty**, uma loja virtual fictícia de maquiagem e produtos de beleza, criada com o objetivo de apresentar produtos, divulgar a marca e proporcionar uma experiência de navegação agradável aos usuários.

O projeto possui uma identidade visual delicada e elegante, utilizando tons de vinho, rosa e creme, com foco na beleza, sofisticação e facilidade de navegação.

## Objetivo
Desenvolver um site para a Amora Beauty, permitindo que os usuários explorem diferentes categorias de produtos, conheçam opções de maquiagem e encontrem inspirações para valorizar sua beleza e personalidade.

## Funcionalidades
- Página inicial com apresentação da marca;
- Navegação entre categorias de produtos;
- Páginas de rosto, contorno, olhos, sobrancelhas, lábios e skincare;
- Seção de acessórios e inspirações;
- Campo de busca de produtos;
- Página de cadastro;
- Página de contato;
- Apresentação de produtos com imagens, nomes e preços.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## Identidade Visual
O design foi desenvolvido com uma proposta moderna e elegante, utilizando uma paleta de cores em tons de vinho, rosa e creme, além das fontes Montserrat e Playfair Display.

## Projeto acadêmico
Desenvolvido como parte de um projeto acadêmico do curso Técnico em Informática para Internet, com o objetivo de aplicar conhecimentos de desenvolvimento web, estruturação de páginas, estilização e programação.
